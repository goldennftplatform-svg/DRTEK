## 9.5 Leaderboards & Community (privacy-respecting by construction)

- **Opt-in only**, handle-based, no emails, no cross-game IDs.
- Boards: Weekly Drip (XP), Cleanest Pipes (CW), Speed Traces (boss times), Class Board (teacher-created rooms).
- Share cards export as images the player saves/sends themselves — the game never auto-posts anywhere (modeling consent).
