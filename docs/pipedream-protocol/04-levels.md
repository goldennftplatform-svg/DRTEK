## Level 1 — Novice User
- **Objectives:** create an email account; understand address anatomy (user@domain); send/receive; watch a streamed video; create a first social profile; recognize that actions generate data records.
- **Key actions:** MailDrop signup form (with live bucket-preview chips), compose+send, Streamly playback, Chirp profile setup, first cookie banner choice.
- **Viz unlock:** Local Loop view (phone → Wi-Fi router → ISP hut → Reservoir). Buckets, basic pipes, sediment intro.
- **New apps:** MailDrop, Streamly, Chirp, Browser, Settings.
- **Level-up magic:** whiteboard expands past classroom wall; horizon line appears.

## Level 2 — Connected Citizen
- **Objectives:** distinguish search/browse/navigate; cookies & sessions; app permissions; notification economics (attention is currency).
- **Key actions:** browser session with 3 cookie choices; per-app permission grants; mute/allow notification tradeoff.
- **Viz unlock:** Ad-Tech overlay (tracker fish, crumb trails, auction lightning between advertisers when a page loads).
- **Magic:** Cookie Confetti Backfire (moment #4).

## Level 3 — Data Aware
- **Objectives:** metadata vs content; inferred attributes; data brokers; how a profile is assembled from small drops.
- **Key actions:** photo upload (EXIF inspector), quiz-style “what do they know now?” predictions, broker registry visit.
- **Viz unlock:** Profile Silhouette panel; Broker Exchange map pins.
- **Climax:** Silhouette fills from the player’s own session history.

## Level 4 — Privacy Defender
- **Objectives:** strong passphrases; password manager; 2FA; phishing recognition; permission revocation hygiene.
- **Key actions:** passphrase forge minigame; manager install sim; 2FA ceremony; Phishing Range; mass-revoke audit.
- **Viz unlock:** Immune System overlay — antibodies, spore model, infection/remediation loops (§07).

## Level 5 — Network Navigator
- **Objectives:** DNS, IPs, packet switching; access technologies (cell tower / satellite / cable); ISPs, backbone, CDNs.
- **Key actions:** resolve a domain at DNS fountain; switch connection type and observe latency; chase a packet across continents.
- **Viz unlock:** Global Map full view; hop-inspector X-ray; connection switcher in Settings.
- **Boss:** manual routing puzzle with budget constraints (latency $, reliability %).

## Level 6 — Traditional Finance Explorer
- **Objectives:** card/ACH/wire rails; clearing houses; correspondent banking; why settlement takes days; fraud economics (~$80B+/yr borne by customers); chargebacks as consumer protection.
- **Key actions:** VaultBank: pay friend (instant rail), schedule bill (ACH), international wire (relay tour); read a statement; respond to simulated fraud alert correctly.
- **Viz unlock:** Money Rails layer over global map; Toll Booths; Settlement Clock.
- **Magic:** $80B Wave seawall defense (moment #5).

## Level 7 — Creator Economy Awakening
- **Objectives:** platform distribution cuts (up to 30% store tax), ad RPM math, payout delays, rights & portability; direct-to-audience alternatives.
- **Key actions:** AppGate Studio listing flow; price a product; watch payout waterfall; export-audience thought experiment (simulated).
- **Viz unlock:** Value-Flow River view with Dams/Toll Booths; side-by-side ledger panels.
- **Magic:** The 30% Waterfall (moment #6).

## Level 8 — Decentralized Apprentice
- **Objectives:** keypairs; public/private signing; self-custody; gas as network fee; nodes replace gatekeepers; testnet-only mindset.
- **Key actions:** KeyCase wallet creation; seed constellation backup drill; receive test-water tokens; first transaction signature with full cinematic trace (§08); gas estimation game.
- **Viz unlock:** Node Mesh layer replacing Gate; Consensus Ring lanterns; Mempool waiting room.
- **All simulated. No real chains, no real funds. Ever (educational mode).**

## Level 9 — Protocol Engineer
- **Objectives:** compose end-to-end routes; smart-contract mental model (simulated vending machine); NFT mint anatomy; AI inference pipeline data-flow; logging into tools with least privilege.
- **Key actions:** Route Editor puzzles ×3; mint an NFT in Workbench; generate an image in Lens Lab and trace its training/inference buckets; connect a tool via scoped API key sim.
- **Viz unlock:** Route Editor sandbox; GPU farm fly-through; contract bytecode waterfall (stylized).

## Level 10 — Grandmaster Technician
- **Objectives:** synthesize everything; articulate centralized vs decentralized tradeoffs; teach-back mode (explain a hop to Brick correctly).
- **Key actions:** Mirror Worlds comparison run; The Grand Tour capstone; graduation ceremony; optional prestige: New Game+ with Hard Tutor (Brick dials sarcasm to 100).
- **Viz unlock:** Everything combined; Grandmaster gold pipe skin; name etched on classroom plaque (local only — privacy!).
