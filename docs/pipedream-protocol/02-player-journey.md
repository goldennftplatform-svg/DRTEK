## 2.2 Phase Detail

### Phase 0 — Onboarding (3 min)
1. **Boot:** glowing pipe logo fills with clean water; title card.
2. **Cohort select:** four friendly door-cards (12–17 / 18–30 / 31–45 / 45+), described by vibe, not demographics (“Fast & meme-y” vs “Patient & thorough”). Changeable anytime in Piper ID.
3. **Guardian flow (Teen only):** friendly consent screen, printable/shareable summary of what the game does (and doesn’t) collect: *nothing*.
4. **Login sim:** unlock the simulated phone (PIN pattern — teaches swipe auth), pick skin tone for Brick, name yourself (local only).
5. **Meet Brick:** whiteboard powers on; Brick draws a bucket; first ambient packet crosses the map behind them. Hook line per cohort.

### Act I — Phone & Classroom (Lv 1–3)
Player masters email, browsing, streaming, social signup; discovers cookies, metadata, profile assembly. World is small: one city-scale map. Emotional arc: **curiosity → mild shock** (the Silhouette moment) → protective instinct.

### Act II — Defense & Networks (Lv 4–6)
Immune-system toolkit, global network anatomy, then banking internals + fraud economics. World expands to full globe; money rails overlay. Arc: **empowerment → gravity** (fraud wave) → competence.

### Act III — Economics & Keys (Lv 7–8)
Platform cut math stings; decentralization arrives as an answer, not a pitch. Wallet creation, seed backup ceremony, first signature with full §08 cinematic. Arc: **indignation → wonder → ownership**.

### Act IV — Engineering (Lv 9–10)
Route editor sandbox = creative play. Mint, generate, connect tools. Grand Tour capstone synthesizes every layer. Arc: **mastery → pride → community** (leaderboards, share cards).

## 2.3 Session & Failure Philosophy

- Lesson unit: 4–8 min, resumable anywhere (state checkpoints each beat).
- **No game-over exists.** Wrong quiz answers spawn extra visualization instead of penalty; mistakes are content.
- Streak system rewards return visits gently (Daily Drip) but never punishes absence.
